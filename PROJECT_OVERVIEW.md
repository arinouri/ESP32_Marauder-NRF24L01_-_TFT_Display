# ESP32 Wireless Hardware Integration — Project Overview

This experimental embedded-systems repository documents work integrating an ESP32 development board with a TFT display and NRF24L01+ radio module, alongside experiments with third-party ESP32 Marauder firmware.

## Hardware referenced

- ESP32 WROOM development board
- ILI9341 SPI TFT LCD
- NRF24L01+PA+LNA radio module
- Breadboard, jumper wires and power stabilization components

## What's in the repository

- `README.md`: wiring and hardware notes
- `marauder_notes.md`: setup and investigation notes
- `tft_test.ino`: Arduino display test sketch

## Responsible testing

Use only equipment, frequencies, networks and devices you own or are specifically authorized to test. Hardware connections and power requirements should be independently checked against the exact module revisions before use.

## Project status

Experimental hardware integration; this overview is not a claim of a fully validated or production-ready security instrument.
